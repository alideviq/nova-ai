# 🌟 NOVA AI

## ✨ المميزات الرئيسية
- 💬 **واجهة محادثة متكاملة** وسلسة.
- ⚙️ **إعدادات متقدمة** للتحكم بالنماذج، واللغة، وسلوك الذاكرة (مرجعية، سياقية، تفاعلية، ودائم).
- 👁️ **معاينة كود حية (Live Code Sandbox)** لتجربة الأكواد بشكل فوري.

## 🔒 ملاحظة أمان مهمة (BYOK)
