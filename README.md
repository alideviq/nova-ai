# 🌟 NOVA AI

مساعد ذكي شخصي متطور، مصمم بـواجهة مستخدم حديثة ومخزن أكواد حي يمنح المستخدم تحكماً كاملاً بالذاكرة والتخصيص وحماية الخصوصية.

## ✨ المميزات الرئيسية
- 💬 **واجهة محادثة متكاملة**: تجربة استخدام سلسة، سريعة، ومتجاوبة مع مختلف الشاشات.
- ⚙ **إعدادات متقدمة**: تحكم كامل بالنماذج، سلوك الذاكرة (سياقية، تفاعلية، دائمة)، وتوجيه سلوك الذكاء الاصطناعي.
- 👁 **معاينة كود حية (Live Code Sandbox)**: بيئة معزولة لتجربة الأكواد، برمجية الألعاب، وتطبيقات الويب بشكل فوري.

## 🔒 حماية الخصوصية والأمان (BYOK)
يعتمد المشروع على نظام **Bring Your Own Key**؛ حيث يتم إدخال مفتاح الـ API يدوياً وحفظه محلياً بالكامل داخل المتصفح عبر (`LocalStorage`). يضمن هذا التصميم عدم مشاركة بياناتك أو مفاتيحك مع أي خوادم وسيطة.
